# Ziyad Safouane · Portfolio

Personal site: AI evaluation, safeguards and human oversight for deployed AI systems.

Live at https://zs-porfolio.vercel.app

A single static page (`index.html`, `style.css`, `script.js`) built with Vite and deployed on Vercel.
The previous React version is kept on the `react-portfolio-feb-2026` branch.

```bash
npm install
npm run dev     # local preview
npm run build   # outputs to dist/
```
