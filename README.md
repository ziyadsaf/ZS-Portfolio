# Portfolio Website

A personal portfolio website showcasing my work and skills as a Software Engineer.

## About

This is my portfolio website built with React and Vite. It includes information about me, my skills, projects I've worked on, and ways to get in touch.

## Features

- Clean, modern design with dark theme
- Smooth scrolling navigation
- Responsive layout that works on mobile and desktop
- Social media links (LinkedIn, GitHub, Email)
- Project showcase section with placeholder cards
- Skills and technologies display

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- React Icons
- Framer Motion (for future animations)

## Project Structure

```
src/
├── components/
│   ├── Navbar.jsx          # Navigation bar with smooth scrolling
│   ├── Hero.jsx            # Landing section
│   ├── About.jsx           # About me and skills
│   ├── Projects.jsx        # Project showcase
│   ├── ProjectCard.jsx     # Individual project card component
│   └── Contact.jsx         # Contact section with social links
├── App.jsx                 # Main app component
├── index.css               # Global styles and Tailwind imports
└── main.jsx                # Entry point
```

## Setup

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open your browser to the local URL shown in the terminal (usually http://localhost:5173)

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally

## Sections

- **Home**: Landing page with my name and title
- **About**: Information about my background, education, and skills
- **Projects**: Showcase of projects (currently placeholders)
